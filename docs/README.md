# docs

Architecture notes and decision records for generate-web-ai.

- `architecture.md` — the current agreed architecture for the MVP, and what
  has been intentionally deferred.
- `v0.2-generative-website-architecture.md` — the v0.2.0 release line
  (in development): the migration from the block-based generator to a
  generative website architecture, the R0–R10 roadmap, migration rules and
  the Feature Preservation Matrix. Release notes: `../CHANGELOG.md`.
- `v0.2-r0-architecture-audit.md` — R0 read-only audit for v0.2: the
  existing experimental generative engine, traced current/downstream paths,
  the evidence-backed Feature Preservation Matrix, high-risk couplings
  (including a build-environment secret exposure), the smallest viable
  architecture, migration gates and the recommended R1 slice.
